PANDUAN PAKET KONFIGURASI OLT

1) Ekstrak file ZIP ini.
2) Copy file .env ke root project sebagai:
   <project-root>/.env
3) Isi SSH_PASS dengan password OLT Anda.
4) Jika menggunakan SSH/CLI set USE_SSH=true.
5) Jalankan aplikasi seperti biasa.

Catatan:
- Nilai OLT diambil dari data yang Anda kirimkan (System Information).
- Jika IP OLT kurang lengkap, sesuaikan OLT_IP sesuai alamat final perangkat.
